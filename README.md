Included:
1. activity_1_2d_animation/activity1.py
2. activity_2_pygame_sprites/activity2.py
3. activity_3_3d_geometry/activity3.py
4. activity_4_projections/activity4.py
5. activity_5_pyopengl/activity5.py
6. Five MP4 demonstration outputs
7. requirements.txt

INSTALL:
    pip install -r requirements.txt

RUN:
    python activity_1_2d_animation/activity1.py
    python activity_2_pygame_sprites/activity2.py
    python activity_3_3d_geometry/activity3.py
    python activity_4_projections/activity4.py
    python activity_5_pyopengl/activity5.py

CONTROLS:
Activity 1:
    1 = Tweening
    2 = Morphing
    3 = Bouncing Dynamics
    ESC = Quit

Activity 2:
    Arrow keys = Move player
    ESC = Quit

Activity 3:
    R = Run 100-object broad-phase test
    ESC = Quit

Activity 4:
    1 = Orthographic
    2 = Cavalier Oblique
    3 = Cabinet Oblique
    4 = Perspective
    X/Y/Z = Rotate cube
    ESC = Quit

Activity 5:
    Arrow keys = Rotate cube
    SPACE = Toggle transparency
    ESC = Quit

MP4 files are rendered demonstration outputs of the same concepts.
